# SOP: New client onboarding

## When this applies
Use this for every new client after the contract is signed, before any delivery work starts.

## Steps
1. Create the client in the CRM and set the account manager.
2. Hold a kickoff call within five working days: confirm scope, contacts, escalation path and change-control process.
3. Collect admin access through the client's own identity platform. Never accept shared passwords by email.
4. Record all credentials in the firm's vault under the client's folder; access is limited to the delivery team.
5. Agree a communication rhythm: weekly status note for projects, monthly service review for managed clients.
6. Add the client to the ticketing system and share the support process document.

## Common mistakes
- Starting work before the data processing agreement is signed.
- Sharing one client's documents as examples with another client. Always use the anonymised case-study library instead.

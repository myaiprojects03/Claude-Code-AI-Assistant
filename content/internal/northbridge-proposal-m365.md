# Northbridge Legal: Microsoft 365 migration proposal

## Summary
Move Northbridge Legal's 180 mailboxes and file shares from on-premises Exchange 2016 and a Windows file server to Microsoft 365, with matter-based SharePoint sites.

## Approach
Phase 1: tenant hardening and identity. Phase 2: mailbox migration in three batches by practice area (litigation, property, private client). Phase 3: matter sites in SharePoint using Northbridge's matter-numbering scheme NBL-YYYY-####.

## Commercials
Fixed price of £38,400 across three phases, invoiced at the end of each phase.
